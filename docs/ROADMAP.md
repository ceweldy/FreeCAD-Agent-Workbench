# Roadmap

## 0.1 foundation

- Native assistant panel
- Codex app-server provider
- Persistent conversations and intent memory
- Tool schemas, policy, transactions, and receipts
- Part primitives, booleans, measurement, and view control

## 0.2 native parametric modeling

- Sketcher geometry and constraints
- PartDesign bodies, sketches, pads, pockets, holes, fillets, and patterns
- Reference-image and viewport attachments
- Visual verification loop
- User approval cards for destructive and external actions

## 0.3 engineering workflows

- Assemblies and joints
- TechDraw pages and dimensions
- Mesh inspection and repair
- CAM and FEM read surfaces, followed by approval-gated writes
- Checkpoints, model revision comparison, and recovery UI

## 0.4 provider ecosystem

- OpenAI Responses API adapter
- Anthropic adapter
- Local OpenAI-compatible adapter
- Provider capability discovery and model selection
- Optional organization policy and audit integrations

## Open-source release gate

- FreeCAD 1.1 runtime matrix on macOS, Linux, and Windows
- Addon Manager packaging validation
- Public security review
- Stable tool and memory schemas
- Contributor documentation and starter tool template
